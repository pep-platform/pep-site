Strategy Module

An effectiveness-led strategy in days, not months

The Strategy Module is built on Box Count's method. It starts with what the partnership is for and builds the plan around it:

  • Objective hierarchies built from the business objective down
  • Partner fit assessed against brand strategy, not a media rate card
  • Rights packages tailored to objectives, so you buy or sell what will deliver
  • Activation budgets set to move the commercial needle
  • Channel plans based on the evidence of what works, from brand building to sales conversion
  • KPI frameworks defined at the outset, not invented at renewal
  • Data sources identified for the metrics you'll be judged on

Rights holders use it to work out what a property can do for a brand, then say it in language a CMO recognises. Brands use it to define what the deal should do before the ink dries.

The output is a written plan with every recommendation tied to the evidence behind it. Rory can run it alongside your team if you'd like an expert in the room.

Measurement Module

No secret sauce here, just transparent performance tracking with intelligent insights

The Measurement Module is built on Data Agents' measurement frameworks, with a model specific to your partnership:

  • Live and batch data feeds, so you see performance in-season and over the long term
  • Performance measured against the objectives and KPIs the Strategy Module set
  • A bespoke model that gets sharper the more it learns about the partnership
  • Insights and recommendations at any point in the lifecycle
  • Questions answered in plain English, straight from the data
  • Scenario modelling: what more or less budget would do
  • Transparent results, with no black-box proprietary metrics

The result is a renewal case both sides believe, because both sides can see how every number was produced. Simon can run it alongside your team if you'd like an expert on the data.
